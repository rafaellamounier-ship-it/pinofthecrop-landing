Política de Privacidade

Última atualização: maio de 2026

Esta Política de Privacidade descreve como o Pin of the Crop ("nós", "nosso" ou "app") coleta, usa e protege as informações dos usuários, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei 13.709/2018).

1. Dados que coletamos

1.1 Identificador de dispositivo (Device ID)

Ao instalar o app, um identificador único (UUID v4) é gerado localmente no seu dispositivo. Esse ID é anônimo — não está vinculado a nenhum dado pessoal como nome, email, telefone ou conta de redes sociais. Ele é usado para:

  • Controlar limites de uso por dispositivo (ex: número de análises diárias)
  • Evitar abusos de acesso automatizado
  • Associar o backup na nuvem exclusivamente ao seu dispositivo
  • Restaurar seus dados após reinstalação do app

O Device ID e um token de autenticação associado são armazenados nos nossos servidores (Railway, EUA) para permitir o backup e a restauração de dados.

1.2 Links analisados

Quando você analisa um link, o URL do conteúdo (Instagram) é enviado ao nosso servidor para processamento pela IA. Esse URL é usado apenas para realizar a análise e não é associado a dados pessoais identificáveis. O vídeo é baixado temporariamente no servidor e excluído automaticamente após o processamento.

1.3 Informações técnicas do dispositivo

Quando você solicita uma análise, as seguintes informações técnicas são enviadas ao servidor junto com o pedido:

  • Modelo do dispositivo (ex: "Samsung Galaxy S23") — para fins de diagnóstico e compatibilidade
  • Versão do app — para identificar comportamentos por versão
  • Plataforma (Android/iOS)

Essas informações são armazenadas anonimamente nos logs de análise e não permitem identificação pessoal.

1.4 Preferências opcionais

O app oferece campos opcionais para melhorar a precisão das análises:

  • Cidade (texto livre, ex: "São Paulo, SP") — ajuda a distinguir restaurantes locais de destinos de viagem
  • Nicho (texto livre, ex: "receitas veganas") — melhora a categorização de conteúdo

Esses dados são enviados ao servidor apenas quando você realiza uma análise e incluídos no backup na nuvem associado ao seu Device ID. O preenchimento é completamente voluntário.

1.5 Dados de uso técnico (logs)

Mantemos logs técnicos mínimos para fins de diagnóstico e segurança, incluindo:

  • Endereço IP (usado temporariamente para rate limiting — não armazenado de forma persistente)
  • Tipo de conteúdo analisado (ex: "filme", "receita") — sem identificação de usuário
  • Tempo de processamento e eventuais erros técnicos

2. Dados que NÃO coletamos

O Pin of the Crop não coleta:

  • Nome, email ou qualquer dado de identificação pessoal
  • Número de telefone
  • Localização GPS ou geolocalização precisa
  • Dados de perfis do Instagram (apenas o URL que você compartilha é processado)
  • Conteúdo de contas privadas (o app só processa conteúdo público)
  • Cookies de rastreamento ou pixels de publicidade
  • Contatos, câmera, microfone ou outros dados sensíveis do dispositivo

3. Armazenamento: local e backup na nuvem

3.1 Banco de dados local

Todos os itens salvos (filmes, receitas, lugares, etc.) são armazenados primariamente no seu dispositivo, usando um banco de dados SQLite local. O app funciona completamente offline — a nuvem é usada apenas como backup.

3.2 Backup automático na nuvem

Para proteger seus dados contra perda (desinstalação, troca de dispositivo), o app realiza um backup automático nos nossos servidores (Railway, EUA), incluindo:

  • Lista completa de itens salvos (títulos, categorias, notas, tags, datas)
  • Imagens em miniatura (thumbnails dos reels), armazenadas como bytes permanentes
  • Preferências do app (tema, idioma, categorias desbloqueadas, ordenação)
  • Conquistas desbloqueadas (badges)

Esse backup é identificado exclusivamente pelo seu Device ID anônimo — não há nenhum dado pessoal associado. O backup é restaurado automaticamente quando você reinstala o app no mesmo dispositivo.

Imagens de posters (filmes, livros) e fotos de lugares são obtidas de APIs externas (TMDB, Google Places) e armazenadas como URLs — os bytes dessas imagens ficam nos servidores dos respectivos provedores, não nos nossos.

4. Backend, processamento por IA e enriquecimento de dados

Quando você solicita uma análise, o URL do conteúdo é enviado ao nosso servidor hospedado na Railway (EUA). O servidor processa o conteúdo via Google Gemini (API de IA da Google) para extrair informações estruturadas (título, categoria, resumo). Consulte a Política de Privacidade da Google para entender como os dados são tratados por essa API.

Para itens de categorias específicas, o app consulta APIs externas para enriquecer os dados com informações adicionais (poster, avaliações, etc.). Nessas consultas, apenas o título do item é enviado às APIs — nenhum dado pessoal é transmitido:

  • TMDB — posters e informações de filmes/séries
  • Google Books — capas e informações de livros
  • Google Places — fotos e informações de lugares
  • Spotify — capas e informações de músicas

5. Compartilhamento de dados

Não vendemos, alugamos nem compartilhamos seus dados com terceiros para fins comerciais. Os únicos provedores externos utilizados são os listados na seção 4, mais a Railway como infraestrutura de servidor.

Cada um desses provedores tem sua própria política de privacidade, que recomendamos consultar.

6. Segurança

Adotamos medidas técnicas razoáveis para proteger as informações transmitidas ao servidor, incluindo comunicação via HTTPS. O backup na nuvem é associado a um Device ID anônimo — sem nome, email ou qualquer dado pessoal que permita identificar o utilizador.

7. Direitos do titular (LGPD)

Nos termos da LGPD, você tem direito a:

  • Confirmação da existência de tratamento de dados
  • Acesso aos dados tratados
  • Correção de dados incompletos ou inexatos
  • Anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados
  • Revogação do consentimento

Como o app não coleta dados pessoais identificáveis, a maioria desses direitos é exercida diretamente no dispositivo (desinstalando o app ou limpando os dados do aplicativo nas configurações do Android). Para dúvidas, entre em contato pelo email abaixo.

8. Menores de idade

O Pin of the Crop não é destinado a menores de 13 anos. Não coletamos intencionalmente informações de crianças. Se você acredita que uma criança forneceu dados ao app, entre em contato conosco para que possamos tomar as medidas adequadas.

9. Alterações a esta política

Podemos atualizar esta Política de Privacidade periodicamente. Alterações relevantes serão comunicadas na descrição do app na Play Store ou dentro do próprio app. O uso continuado do app após as alterações constitui aceite das novas condições.
